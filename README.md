# Dress-Up Learning Games

Tap-to-play learning games for preschoolers. Everything is big, chunky buttons, and the game says each color, shape, number and letter out loud.

## Zahra's Dress-Up (`index.html`)

A dress-up game for a 3–4 year old who is learning colors, shapes, numbers and how to write her name.

- **Face** – take a selfie with the camera button (or use the cartoon face), then paint makeup with a finger or stamp on stickers.
- **Nails** – pick a color and a pattern (plain, dots, stripes, stars, hearts), then tap each finger. It counts "one, two, three, four, five" and throws confetti when all five are done.
- **Shirt** – one tap fills the shirt with the chosen color and pattern; add shapes on top.
- **Name** – stamps Z‑A‑H‑R‑A one letter at a time, with the next letter bouncing, and cheers "Zahra!" at the end.
- **Undo** is one tap; **Clear** needs two taps so a picture isn't wiped by accident. The speaker button turns the voice off.

### Play it

It's a single HTML file with no build step. Open `index.html` in a browser, or turn on GitHub Pages (Settings → Pages → deploy from `main`, root) to play it on a phone or tablet. The camera button opens the device's front camera and uses the photo it takes.
